# LeadMap

Plataforma de prospecção B2B para Moçambique.

**Encontre empresas no Google Maps, enriqueça contatos e venda com IA.**

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router
- Lucide Icons

## Desenvolvimento

```bash
npm install
npm run dev
```

## Estrutura

- `src/lib/site.ts` — configuração central
- `src/pages/Landing.tsx` — página inicial
- `src/pages/Login.tsx` — autenticação
- `src/pages/Dashboard.tsx` — área logada
- `src/components/` — Header, Footer, Layouts

## Cidades prioritárias

Maputo · Matola · Beira · Nampula · Tete · Quelimane
